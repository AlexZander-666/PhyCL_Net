# Orange Pi CPU records

The fixed and prepared-window JSON records match the paper's rounded p50/p95, RSS, model-file size, shape and warmup/repeat counts. They are retained byte-for-byte from the previously public repository. The original export model, checkpoint hash and matching export manifest are absent. Historical status flags do not resolve model identity. These records therefore document their saved board execution, without establishing that the no-MSPA main model was the exported architecture. See [hardware scope](../../../docs/REVIEWER_GUIDE.md#hardware).
