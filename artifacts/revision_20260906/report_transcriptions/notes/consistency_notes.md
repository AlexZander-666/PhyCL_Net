# 数据文件包的一致性说明

本文件按上一级 [README.md](../README.md) 统一包内命名与用途说明。**原文值保留在 reported 文件，算术结果单列 derived。** `report_tables/` 保存 `result.md` 的全部 23 表；各实验目录内名称含 `reported` 的文件保留相应原文汇总值；`derived/` 及 `classification/{faa,no_faa}/derived_summary.*` 保存从可见明细计算的描述统计。以下差异分别记录，SD 使用样本标准差（ddof=1）；均值单位为百分比，差值单位为百分点。

文件清单的 `origin` 表示按 README 用途统一的文件生成类别，`source_locations` 保留对应报告位置或旧文件路径。`local_generated_data` 指本地生成的数据文件，数据值的原文位置仍可追溯；`report_table_export` 指原文表格导出；`derived_statistics` 指明细的描述性算术结果。旧日志副本已按清理范围移除；恢复操作日志保持 `actual_recovery_operation` 身份。
