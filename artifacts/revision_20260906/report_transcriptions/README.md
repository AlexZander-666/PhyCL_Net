# Selected report transcriptions

The CSV files and `notes/consistency_notes.md` are exact copies from the source
supplement accompanying the revised manuscript. Only the complete FAA grid,
the cited hardware tables, and interpretation notes are selected here. They
are report transcriptions, not original training or device logs.

The copied consistency note discusses the larger source package as well. Its
references in plain text to `report_tables`, `derived`, `verification.json`,
thresholds and an independent cohort describe that original package, not files
promised in this selected subset. The current available files are enumerated in
[the source manifest](../../manifests/revision_source_manifest.json).

The revised paper uses the corrected descriptive FAA SD and reported processing
boundaries. The historical `readme_time`, source “end-to-end” column labels and
pass/checklist annotations remain unchanged for traceability; they are not
independently verified experiment times, integrated alert delays or cost-gate
certifications. See [the reviewer guide](../../../docs/REVIEWER_GUIDE.md).
