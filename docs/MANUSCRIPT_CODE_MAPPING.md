# Manuscript-to-code correspondence

This is an inspection map for the supplied 2026-09-06 paper and the implementation inherited from public commit `9dbbd3b9def673b1389db82dee42fb0aee6a16aa`. This packaging update does not replace model/training code or assign that commit to an undocumented historical run.

| Paper element | Existing implementation | Correspondence / qualification |
| --- | --- | --- |
| PhyCL-Net / spectral baseline | [MODEL_ALIASES](../code/phycl_net_experiments.py), [PhyCLBlock](../code/models/phycl_net.py) | `phycl` defaults to no-MSPA; `phycl_full` includes MSPA. The baseline is not the report's no-FAA arm. |
| Stem and three stages | [PhyCLNet](../code/models/phycl_net.py), [efficient blocks](../code/models/modules/efficient.py) | 48/96/192 channels, two blocks per stage, strided transitions and pooled two-logit classifier. Softmax is applied in evaluation. |
| PDK routing | [DynamicKernelBlock](../code/models/modules/dks.py) | Kernels 7/15/31/63; ten temporal and two rFFT-derived descriptors on block features; routing modulation and adaptive mixture. No claim of FFT-free execution. |
| FAA | [FallAwareAttention](../code/models/modules/faa.py), [axis attention](../code/models/modules/attention.py) | Gaussian length 5, first/second differences, global context and learned mask. **Ordering difference:** code smooths input F, while the revised schematic smooths axis-attended F_a. No checkpoint-matched equivalence has been established. |
| Fusion | [CrossGatedFusion](../code/models/phycl_net.py) | Three pooled global MLP logits in each direction; their `(3,5,7)` configuration controls gate count, not temporal kernel sizes; channel-pooled spatial gate uses k=7. Outer block residual scale starts at zero. |
| Contrastive heads | [PhyCLNet.forward](../code/models/phycl_net.py), [loss](../code/losses/__init__.py) | **Count difference:** retained code attaches one head per block per stream (six blocks × two = 12); paper describes three stages × two = six. Eager forward computes auxiliary outputs; export freezes a logits-only trace. Do not equate eager timing with the final stripped inference graph without checking it. |
| Preprocessing | [SisFallDataset](../code/phycl_net_experiments.py), [historical protocol](../artifacts/revision_20260906/historical_runs/preprocessing.json) | Archived/public loader uses native 200Hz, per-record channel z-score, 512/256 windows, padding short records; it does not implement paper's stated 200→50Hz + fourth-order 5Hz filter. `sample_rate=50` scales descriptors; it does not resample the data. |
| Training | [Entry point](../code/phycl_net_experiments.py), [historical args](../artifacts/revision_20260906/historical_runs/) | Paper specifies CE + 0.1 contrastive loss. Historical settings include different augment/auxiliary-loss choices. Recorded args are evidence, not proof of a fully matched paper recipe. |
| Dual-view contrastive objective | [train_epoch](../code/phycl_net_experiments.py), [HierarchicalTFContrastiveLoss](../code/models/modules/tfcl.py) | Retained training makes one model call per batch and contrasts time/other-stream embeddings, with optional cross-layer and supervised terms. The paper specifies corresponding heads across two independently augmented views. Those objectives are not established as equivalent. |
| ROC constraints | [Standalone evidence checker](../scripts/verify_reviewer_evidence.py) | All score ties together, observed points only, common inequality constraints. Baseline recalculation agrees; this is empirical discrimination, not validation-calibrated deployment thresholds. |
| Export and device benchmark | [Export](../code/scripts/export_model_for_edge.py), [Orange Pi runner](../code/scripts/benchmark_on_orangepi.py) | Tooling can generate an export and benchmark record. Historical record identity requires the actual export manifest and checkpoint hashes. |
